title: "A busca pela AGI resolve o problema dos três corpos na computação"
deck: "A computação tem três corpos: os teóricos que enunciam o que um sistema deve fazer, os construtores que o fabricam e os usuários que o executam. Cada corpo é coerente por si só. A instabilidade está nas interfaces entre eles, onde cada lado supõe que a passagem não existe ou que é tarefa de outro, de modo que a suposição nunca é escrita nem verificada. O artigo usa com cuidado o problema dos três corpos da mecânica celeste, separa analogia de mecanismo e enuncia a tese das interfaces como definições, proposições, protocolos e falseadores. Um sistema que visa a inteligência geral precisa agir nos três corpos e em cada nível da pilha, então não pode deixar implícita nenhuma suposição de interface. Buscado a sério, esse objetivo obriga a tornar cada suposição explícita e verificada, e numa pilha com todas as interfaces verificadas uma correção permanece onde é feita e se propaga para cima. As verificações de interface em toda a pilha do Reality Code Engine são a primeira evidência."
