## 摘要

RCE-VC 是一项版本控制设计与小型 Rust 参考实现（公开树 `openIE-dev/rce-vc` 提交 `8bf9c9af`，包含无依赖确定性核心 `rcevc-core` 与读写 Git 对象的 `rcevc-proj-git`）。任意数量的人或程序可同时向同一共享状态提交变更：具名检查接受变更后状态时予以准入，否则予以拒绝并记录原因；写作者仍可继续使用 Git。该参考实现并非 Reality Code Engine 语言本身，但采用同一套框架：形式（Form）、全函数步进、哈希链日志、无名称键，以及将模型放在最末一档的档位阶梯。

**用平常话说**

1. 任意数量的人和程序可同时写入。只有当具名检查在声明契约下接受变更后状态时，变更才进入共享历史；否则变更被拒之门外并写下原因，由谁编写并不决定结果。
2. 互不触及同一依赖闭包的变更无需彼此等待即可准入；发生重叠时，预先写明的成本表对通过检查的结果排序，且包括已解决冲突在内的每个已接受结果都会被复用，模型仅在更便宜步骤失败后才被调用。
3. 参考实现读写普通 Git 历史，因此写作者无需离开 Git。在实测构建上，从数百个单元到 100,000 个单元，单核准入一次变更保持在十分之二毫秒以内（100,000 单元为 188 微秒）；收据上的 `est_uj` 是声明的成本表而非电表读数，未测量任何焦耳。
