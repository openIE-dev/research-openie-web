## 摘要

本文阐述一项命题、若干假设（H1 至 H15）、证伪条件与工作计划。文中报告的结果是不需要学习型提议者的第 0 阶段基线测量（形式语料库、无名称形式空间、确定性事件流与对抗形式）；由于尚未训练任何学习型提议者，本文不报告学习型提议者的实测结果。JEPA 是前提：预测意义的摘要，而非表面文本。主题是世界编程，即在形式空间上运行的任意学习型提议者，并以编程定律作为接受规则。判定的一半（提交门槛、精确重放、投影，以及以整数单位计费并标注为 `est_j` 的能量估计值）见 [Reality Code Engine](/papers/rce/) 论文；本文讨论提议者一侧，安全性从不依赖模型本身。

**用平常话说**

1. 主题是世界编程。代码世界由程序形式（Form）的空间加上精确的下一步状态与接受规则（编程定律）组成。JEPA 是前提而非全部方法：预测意义摘要，而不是代码的下一个词。这里的 AI 指任何学习型提议者，而非单一架构。
2. 模型只负责提议，检查器负责裁决。轨迹训练解码器、扩散模型、证明检查器内的强化学习、演化搜索、库学习与受限解码都可放入该槽位。提议者更换时门槛不变，安全性不取决于提议者是否正确。
3. 实测下界明确标注，未完成的工作保持未完成状态：185 个手写程序的中位描述长度比为 9.34；1,275 个已接受模糊变异体中发现 0 次不变量破坏；六个目标上的 10,500 条流重放完全一致；确定性阶梯以 0 次模型调用闭合 151 项任务中的 111 项（73.5%），剩余 40 项。尚未训练学习型提议者，也未为未发生的运行填写任何焦耳读数。
