## 要旨

本稿はテーゼ、仮説（H1 から H15）、反証条件、および作業計画を述べる。報告される結果は学習済み提案者を必要としないフェーズ 0 の測定（形式コーパス、名前なし形式空間、決定性ストリーム、敵対的形式）であり、学習済み提案者はまだ訓練されていないためその結果は報告されない。JEPA は表層テキストではなく意味の要約を予測するという前提である。主題は World Coding、すなわちコーディングの法則を受理規則とする形式上の任意の学習済み提案者である。決定を担う半分（コミットゲート、厳密な再生、射影、および整数単位で数えられ `est_j` とラベル付けされるエネルギー推定値）は [Reality Code Engine](/papers/rce/) 論文に記述されており、ループ内のいかなるモデルも提案のみを行い、安全性がモデルに依存することはない。

**平易な言葉で**

1. 主題は World Coding である。World of Code はプログラム形式（Form）の空間と、次状態および受理対象に関する厳密な規則（コーディングの法則）からなる。JEPA は手法全体ではなく前提であり、コードの次の語ではなく意味の要約を予測する。
2. モデルが提案し、チェッカーが決定する。トレース学習デコーダ、拡散、証明チェッカー内の強化学習、進化的探索、ライブラリ学習、制約付きデコーディングのいずれもその枠に入ることができ、提案者が変わってもゲートは変わらない。
3. 測定された下限はラベル付きで保たれ、未完の作業は未完のまま明記される。手書きプログラム 185 本の記述長比の中央値は 9.34、受理された変異体 1,275 件の不変条件違反は 0 件、6 ターゲット 10,500 ストリームの再生は一致し、決定論的ラダーはモデル呼び出し 0 回で 151 件中 111 件（73.5%）を閉じた。まだ行われていない実行についてジュール数を捏造することはない。
