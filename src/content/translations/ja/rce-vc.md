## 要旨

RCE-VC はバージョン管理の設計と Rust による小規模な参照実装（公開コミット `8bf9c9af` の `openIE-dev/rce-vc`）である。人間やプログラムなど多数の書き手が単一の共有状態に対して変更を提出し、名前付きの検査が結果を受理するか、理由を残して拒否する。書き手は Git にとどまることができる。この参照実装は Reality Code Engine 言語そのものではないが、形式（Form）、全域的な遷移ステップ、ハッシュ連鎖ログ、名前なしキー、そしてモデルを最後に置くギアのラダーという同じ枠組みを用いる。

**平易な言葉で**

1. 何人の人間やプログラムでも同時に書き込める。名前付きの検査が結果を受理したとき変更は共有履歴に入り、受理しなければ変更は外にとどまり理由が記録される。誰が書いたかは決定に関与しない。
2. 同じ対象に触れない変更は互いを待つ必要がない。重なる場合は事前に記されたコストが合格候補を順位付けし、解決済み競合を含め一度受理された結果は再利用される。モデルはより安価な段階が失敗した後でのみ呼ばれ、その答えも検査に合格しなければならない。
3. 参照実装は通常の Git 履歴を読み書きするため、書き手は Git を離れる必要がない。実測ビルドでは変更の受理は数百ユニットから 100,000 ユニットまで 1 コアで 0.2 ミリ秒未満（188 マイクロ秒）に収まった。レシート上の `est_uj` は明示された表であり、ジュール測定ではない。
