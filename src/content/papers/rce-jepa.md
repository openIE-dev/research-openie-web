# RCE-JEPA: World Coding, with JEPA as Premise

RCE-JEPA (RCE is the Reality Code Engine; JEPA is a Joint Embedding Predictive Architecture) keeps its name so the work stays findable. The subject is World Coding. JEPA is the premise: a learned model predicts a compact summary of a program instead of writing the next word-piece of text. A World of Code is the space of canonical program Forms plus the exact transition and acceptance rules (the Laws of Coding). The proposer slot is any learned model. The checker decides. Hypotheses H1 to H15 are stated in the paper. The measured floors are a median description-length ratio of 9.34 over 185 hand-written programs, 0 invariant violations among 1,275 fuzzed mutants, 0 replay mismatches on 10,500 streams across six targets, and a deterministic ladder that closed 111 of 151 tasks (73.5%) with zero model calls, leaving 40. No learned proposer has been trained. H15, the comparison of proposer types on those 40 tasks at equal energy, is unfinished. Energy means electrical energy in joules, with idle use subtracted when a meter reading exists. This page does not fill in a joule count for a run that has not happened.
