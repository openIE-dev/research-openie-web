## No-pay routes (searched, not assumed)

- EU conformity: module-A internal production control (deployed safety functions frozen at
  replay admission, not self-evolving) + technical file + harmonised standards.
- RTOS: seL4 (open, machine-checked) / Zephyr + free SIL3 self-test library; emitters built.
- Assurance: SLSA/in-toto provenance + open evidence + free compliance checkers; no paid audit.
- Fleet/RaaS: owned fleet, per-joule on own hardware; no debt facility.
- Scale: reuse + corpus mining + federated/hybrid compute-light methods; cloud GPU available
  for the occasional heavy step (CUDA kernel emitted as data).

## Open (named, quantified, never faked)

- Contact manifolds beyond convex polygons (meshes, concave, arbitrary manifolds).
- Production-scale FormJEPA / tracing-JIT (seeds + reuse curve built; scale is the frontier).
- Language-specific grammar remainder (exotic nodes) beyond the measured declaration coverage.
- Preemption beyond statement granularity; true hardware-in-the-loop certification.
