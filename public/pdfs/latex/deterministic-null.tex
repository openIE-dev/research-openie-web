\section{0. Overview}\label{overview}

Empirical evaluations of agentic artificial intelligence routinely
compare one stochastic language model against another, leaving
unmeasured how much task completion requires a neural substrate at
decision time rather than a fixed integer procedure over an explicit
store of verified prior cases. This study constructs, freezes, and
audits that missing control --- \textbf{Deterministic Null
(\texttt{Shape\ D})} --- and tests the per-class null hypothesis
\(H_{0,k}: \Delta_k = p_{\text{model},k} - p_{\text{null},k} \le \delta\)
at margin \(\delta = 0.05\) (\texttt{5.0} percentage points) across two
cryptographically pre-registered confirmatory experiments
(\texttt{4,030} post-beacon held-out instances across \texttt{exp-001}
and \texttt{exp-002}), a multi-turn repository bug-repair study
(\texttt{6} multi-file Python repositories), and companion
reviewer-closure suite \texttt{exp-003} (multi-vendor non-Anthropic
cloud breadth, extended-thinking and multi-turn resolution of unique
\texttt{3-\allowbreak{}satisfiability} formulas, and real upstream GitHub defect
repair with \texttt{0}-call replay). Local Apple M5 Max energy counters
(\texttt{IOReport} and \texttt{proc\_\allowbreak{}pid\_\allowbreak{}rusage}) are recorded as
operating-system/on-chip \texttt{reported\_\allowbreak{}j} values; closed-model
remote server energy is recorded strictly as \texttt{not\_\allowbreak{}available}; no
hardware rail or wall-plug power monitor was attached
(\texttt{board\_\allowbreak{}metered\ =\ false}, \texttt{measured\_\allowbreak{}j\ =\ None}).

\textbf{In plain words}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Most agent benchmarks compare model A with model B without asking how
  much a zero-model lookup loop over verified prior examples already
  solves.
\item
  Across \texttt{2,840} instances drawn from bounded algebraic,
  formal-proof, and structured transaction families (\texttt{exp-001},
  Track-A), a frozen integer case table (\texttt{0} model calls at
  decision time) matches frontier cloud models on \texttt{9} of
  \texttt{10} class-tier cells, failing only on \texttt{12} unindexed
  free-text customer idioms (\texttt{+36.40} percentage points for
  \texttt{Claude\ Opus\ 5.\allowbreak{}5}).
\item
  Across \texttt{1,190} unique instances from externally authored public
  benchmarks (\texttt{exp-002}, Track-B: Berkeley Function-Calling
  Leaderboard \texttt{v3}, Sierra \texttt{tau-bench} Retail,
  \texttt{BigCodeBench\ v0.\allowbreak{}1.\allowbreak{}3}, and \texttt{SWE}
  (software-engineering)-bench Verified), plus \texttt{exp-003}
  multi-vendor evaluations (\texttt{OpenAI\ gpt-\allowbreak{}oss-\allowbreak{}120b}
  \texttt{+45.83} percentage points, \texttt{xAI\ Grok\ 4.\allowbreak{}20}

  \texttt{6} real upstream GitHub defect commits (\texttt{5/6} patched
  and \texttt{pytest}-verified by \texttt{Opus\ 5.5}, then \texttt{5/6}

\subsection{1.1 Lineage, prior-art boundaries, and same-house
disclosure}\label{lineage-prior-art-boundaries-and-same-house-disclosure}

No novelty is claimed for the decision loop itself. Case-based
retrieve--reuse--revise--retain cycles date to Stanfill and Waltz (1986)
and Aamodt and Plaza (1994); tabular pole-balancing dates to Michie and
Chambers (1968); fuzzy rule tables date to Mamdani and Assilian (1975)
and Wang and Mendel (1992); satisfiability proof logging via
\texttt{RUP/DRAT} dates to Goldberg and Novikov (2003) and Wetzler,
Heule, and Hunt (2014). Prior Open Interface Engineering works ---
\href{https://research.openie.dev/papers/gates/}{Metered Commit Gates},
\href{https://research.openie.dev/papers/satiation/}{Task Satiation
vs.~Aggregate Rebound},
\href{https://research.openie.dev/papers/rce/}{The Reality Code Engine},
and \href{https://research.openie.dev/papers/lut-adapt/}{Downward LUT6
Compilation} --- are \texttt{{[}same\ house{]}} companions cited for
architectural context, never as independent confirmation.

A 69-source prior-art audit and 36-finding red-team review
(\texttt{docs/\allowbreak{}DOSSIER.\allowbreak{}md} in
\href{https://github.com/openIE-dev/deterministic-null}{openIE-dev/deterministic-null})
established one narrow gap in the 2024--2026 agent evaluation
literature: existing agent benchmarks overwhelmingly omit non-neural
controls, existing non-neural baselines lack pre-registered held-out
store freezes, and existing energy studies of language-model agents
include no zero-model control arm on the same host.

\section{2. Machine Specification, Arms, and Five-Language
Conformance}\label{machine-specification-arms-and-five-language-conformance}

\subsection{2.1 The eight-step integer loop and complexity
caps}\label{the-eight-step-integer-loop-and-complexity-caps}

Every \texttt{Shape\ D} null arm executes an eight-step 64-bit signed
integer loop (\texttt{Q\ =\ 1,\allowbreak{}000,\allowbreak{}000} fixed-point scaling, zero
IEEE-754 floating-point instructions, zero neural calls at decision
time):

\[\texttt{OBSERVE} \;\to\; \texttt{REDUCE} \;\to\; \texttt{FUZZ} \;\to\; \texttt{LOOKUP} \;\to\; \texttt{ACT} \;\to\; \texttt{VERIFY} \;\to\; \texttt{MUTATE} \;\to\; \texttt{WRITE}.\]

During \texttt{dev} construction, \texttt{WRITE} appends verified
records (\texttt{src} tagged \texttt{lit:}, \texttt{human:},
\texttt{mut:}, or \texttt{llm:}) to a canonical \texttt{JSONL} log and
compiles a zero-copy \texttt{POSIX\ mmap} open-addressed binary hash
table (\texttt{DNULLMM1}: 64-byte header plus 48-byte slots). Before
\texttt{test} evaluation, the store is frozen read-only by
\texttt{SHA-256} digest; \texttt{VERIFY}, \texttt{MUTATE}, and
\texttt{WRITE} execute zero test-time updates, and pre/post store
digests are asserted byte-identical. To prevent smuggling a general
solver into per-class code (\texttt{TH2}), each class's function table
(\texttt{REDUCE} + \texttt{ACT}) is capped at
\texttt{\textless{}=\ 4,096} gzipped bytes and
\texttt{\textless{}=\ 50,000} primitive operations per call
(\texttt{S-3}), and no learned natural-language reducer is permitted
(\texttt{S-4}).

\section{6. Limitations, Falsifiers, and Unfinished
Work}\label{limitations-falsifiers-and-unfinished-work}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{No physical rail or AC wall-plug power meter
  (\texttt{board\_\allowbreak{}metered\ =\ false}, \texttt{measured\_\allowbreak{}j\ =\ None})}:
  All energy figures in this study are Apple Silicon on-chip
  \texttt{IOReport} (\texttt{L2}) and kernel \texttt{ri\_\allowbreak{}energy\_\allowbreak{}nj}
  (\texttt{L3}) \texttt{reported\_\allowbreak{}j} counters on a host running
  concurrent jobs; \texttt{L0} AC wall-plug measurements
  (\texttt{Shelly}/\allowbreak{}\texttt{Yokogawa}, capturing PSU, DRAM, and NVMe
  losses) on a quiesced target machine remain open.
\item
  \textbf{Self-administered benchmark selection vs.~human outside-party
  Tier 3}: Although Track-B (\texttt{exp-002}) and \texttt{exp-003}
  evaluated externally authored public benchmarks and upstream GitHub
  commits locked before \texttt{drand} round \texttt{6664089}, a sealed
  Tier-3 benchmark authored and held in escrow by an independent human
  third party has not yet been run.
\item
  \textbf{Finite-budget non-necessity}: Every
  \texttt{"Relevance\ shown"} verdict is strictly relative to the
  declared \texttt{dev} sample (\texttt{100–150} instances) and
  \texttt{4,096\ B} function-table cap; as Closure B
  (\texttt{formal.\allowbreak{}unique\_\allowbreak{}3sat\_\allowbreak{}drat}) illustrates directly, a
  zero-store classical \texttt{CDCL+DRAT} solver (\texttt{B1}) solves
  \texttt{100\%} of instances where a \texttt{TH2}-capped local walk
  stops at \texttt{78.0\%}.
\end{enumerate}
