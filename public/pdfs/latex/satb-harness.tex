\begin{abstract}
\noindent
Benchmark comparisons across language models and coding agents routinely conflate neural capability with wrapper policy and conflate shared-host operating-system counters with physical rail joules. On \texttt{Terminal-Bench 2}, swapping only the surrounding harness shifted \texttt{Gemini 2.5 Pro} task resolution by $17$ percentage points (\texttt{Terminus-2} vs.\ \texttt{OpenHands}). This paper specifies and empirically audits the \textbf{Satiation Benchmark (\texttt{SATB})} harness and telemetry architecture: (1) a fixed sequential Rust reference harness (\textbf{\texttt{Lane B}}: \texttt{TEMPLATE\_v0}, deterministic $80\%$-window oldest-tool-output elision \texttt{ContextRule\_v0} making zero compaction model calls, sequential \texttt{TOOLS\_v0} inside a network-isolated \texttt{/work} sandbox with \texttt{Truncate\_v0} $8+8\;\text{KiB}$ bounds, and canonical outcomes \texttt{pass | fail | refuse | killed}); (2) a single loopback proxy bridge (\textbf{\texttt{Shapes D, M, H, I}}) enforcing mandatory token usage (\texttt{C7}) and isolating upstream API keys from \texttt{/work} (\texttt{C6}); (3) a five-block \texttt{JCS} (\texttt{RFC 8785}) \texttt{SUT} fingerprint and start/end canary gate; and (4) a five-level rootless telemetry engine (\textbf{\texttt{L0--L4}} crossed with attribution labels \textbf{\texttt{A1--N}}). Live verification on an \texttt{Apple M5 Max} workstation ($128\;\text{GB}$ unified memory, \texttt{macOS 27.2.1}, \texttt{macmon 0.12.0}; on-chip counters recorded as \texttt{reported\_j}) confirms \textbf{12/12} \texttt{C1--C12} checks ($0$-byte replay drift across $14$ turns and $149{,}747\;\text{B}$; $2.073\;\text{ms}$ mean 4-PID process-group \texttt{SIGKILL} cleanup vs.\ $2{,}000\;\text{ms}$ ceiling), exposes \texttt{HTTP 400} \texttt{temperature = 0} deprecation on \texttt{Claude Opus 5.5}/\texttt{Sonnet 5.5} and residual \texttt{seed = 42} variance on \texttt{Cerebras gpt-oss-120b} ($2/8$ distinct outputs), measures boundary \texttt{rusage} observer overhead at $\mathbf{0.011\;\text{mW}}$ ($108\;\mu\text{J}/10\;\text{s}$) vs.\ $66.44\;\text{mW}$ ($0.177\%$) at $10\;\text{Hz}$, demonstrates \texttt{CPU}-proportional (\texttt{Kepler}, label \texttt{C}) splitting diverging from sequential boundary counters (\texttt{B}) by $\mathbf{32.59\%\text{--}35.86\%}$ on \texttt{L2} (\texttt{Falsifier 3}), and audits \textbf{188} shared-host \texttt{L2} windows (\texttt{Falsifier 6} dropping $124$ drifted net subtractions while preserving $100\%$ of raw \texttt{L2}/\texttt{L3} \texttt{reported\_j} channels) alongside $24/24$ and $6/6$ multi-file completion parity against \texttt{Claude Code 2.1.330} (\texttt{Falsifier 8}).
\end{abstract}

\section{Harness Survey, Design Closures (\texttt{OQ-1..OQ-6}), and \texttt{Lane B} Protocol}

Production and benchmark agent wrappers---including \texttt{mini-swe-agent} (stateless \texttt{subprocess.run}, linear history), \texttt{SWE-agent ACI} (100-line viewer, linter-gated edits, history folding), \texttt{UK AISI Inspect react()} and \texttt{Inspect Agent Bridge}, \texttt{Terminus-2 / Harbor} (\texttt{tmux} keystrokes + 3-stage summarization), \texttt{Codex CLI} (\texttt{Landlock}/\texttt{Seatbelt} + \texttt{apply\_patch}), \texttt{Claude Code} (\texttt{Bash} + file tools + \texttt{auto-compact}), \texttt{OpenHands} (\texttt{ACP} containers + condenser), \texttt{ARC-AGI-3}, and \texttt{OSWorld} (\texttt{pyautogui} sliding trajectory)---embed distinct context-compaction and retry policies. \texttt{SATB} eliminates this confound via six normative closures:
\begin{enumerate}[leftmargin=1.5em,itemsep=1.5pt,topsep=1.5pt]
  \item \textbf{\texttt{ContextRule\_v0} (\texttt{OQ-1}):} At $\ge 80\%$ of the declared context window, \texttt{Lane B} deterministically replaces oldest tool outputs with \texttt{[ELIDED\_BY\_CONTEXT\_RULE\_V0]} while keeping \texttt{system(TEMPLATE\_v0)}, initial \texttt{user(bundle)}, and the last $8$ tool outputs verbatim with \emph{zero} model calls (\texttt{killed(context\_ceiling)} fires only if retained messages exceed $100\%$).
  \item \textbf{\texttt{TOOLS\_v0} (\texttt{OQ-2}):} Six \texttt{JCS}-hashed schemas (\texttt{exec}, \texttt{read\_file}, \texttt{write\_file}, \texttt{list\_dir}, \texttt{submit}, \texttt{refuse}) with byte-safe \texttt{Truncate\_v0} ($8\;\text{KiB}$ head $+$ $8\;\text{KiB}$ tail) inside network-blocked \texttt{/work}, avoiding \texttt{mini}-style shell-escaping failures.
  \item \textbf{Surjective 5-to-4 Outcome Mapping (\texttt{OQ-3}):} Maps \texttt{\{completed, incorrect, malformed, refused, no\_\allowbreak submission\}} onto \texttt{\{pass, fail, refuse, killed\}} with lossless \texttt{sub\_\allowbreak reason} (\texttt{malformed} $\to$ \texttt{fail:\allowbreak malformed\_\allowbreak submission}; missing usage $\to$ \texttt{killed:\allowbreak usage\_\allowbreak missing}), keeping all four outcomes in denominator $n$ with zero test-time verifier feedback.
  \item \textbf{Primary Energy Boundary (\texttt{OQ-4}), Rootless Rule (\texttt{OQ-5}), and Closed-API Rule (\texttt{OQ-6}):} Whole-\texttt{SUT} raw window energy (\texttt{A2}) is primary; collection is strictly rootless (\texttt{macmon} + \texttt{proc\_\allowbreak pid\_\allowbreak rusage} on macOS, zero \texttt{sudo}; \texttt{PLATYPUS}-isolated supervisor-\texttt{UID} \texttt{udev} group on Linux); closed-API server energy is written literally as \texttt{"not\_\allowbreak available"} (label \texttt{N}) unless per-request provider-attested (\texttt{P}), barring fleet sustainability medians ($0.24\;\text{Wh}$, $0.34\;\text{Wh}$, $1.14\;\text{gCO}_2\text{e}$).
\end{enumerate}

\section{Adapter Bridge (\texttt{Shapes D, M, H, I}), Five-Block Fingerprint, and \texttt{C1--C12}}

External systems attach to \texttt{satb-\allowbreak supervisor} via four shapes: \textbf{\texttt{Shape D}} (\texttt{Deterministic Null} \texttt{N0}/\texttt{N1} over frozen \texttt{DNULLMM1} \texttt{mmap} stores, $0$ proxy calls), \textbf{\texttt{Shape M}} (OpenAI-compatible or translated \texttt{Anthropic}/\allowbreak\texttt{Gemini}/\allowbreak\texttt{xAI} endpoints), \textbf{\texttt{Shape H}} (harness-in-a-box \texttt{CLI}s such as \texttt{Claude Code}, \texttt{Codex CLI}, \texttt{OpenHands}, and \texttt{Terminus-2} reading \texttt{/work/\allowbreak task/\allowbreak BUNDLE.md} with base URL locked to \texttt{satb-\allowbreak proxy} and \texttt{--strict-\allowbreak mcp-\allowbreak config} \texttt{submit}/\texttt{refuse}), and \textbf{\texttt{Shape I}} (\texttt{Inspect} solvers at \texttt{attempts = 1}). Every session locks a five-block \texttt{JCS} fingerprint (\texttt{model}, \texttt{serving}, \texttt{sampling}, \texttt{harness}, \texttt{envelope}; unknown fields set to \texttt{"not\_\allowbreak available"}); any mid-session hash or \texttt{system\_\allowbreak fingerprint} drift marks session receipts \texttt{void}.
