\section{0. Overview}\label{overview}

This study examines how a computing system can compile repeated
neural-model work downward into fast Boolean table lookups and certified
canonical skills without losing exact output parity or promoting
unverified guesses into trusted rules. It reports software and
unbuffered input/output measurements, register-transfer-level synthesis
and cycle simulations, dual-channel operating-system / on-chip energy
counter readings (\texttt{reported\_\allowbreak{}j} on Apple M5 Max and Linux Running
Average Power Limit counters), and labeled analytical energy estimates
(\texttt{est\_j}). No wall or rail joule monitor was attached in this
repository (\texttt{measured\_\allowbreak{}j} is unset; \texttt{board\_\allowbreak{}metered} is
false).

\textbf{In plain words}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Most inputs a deployed system sees repeat patterns it has already
  solved, so running a full floating-point neural network on every step
  wastes compute and memory bandwidth.
\item
  The reference places a reconfigurable 6-input truth-table
  (\texttt{LUT6}) lookup tier ahead of streaming state-space and
  foundation models, and compiles answers downward into lookup memory
  pages only after an explicit check certifies them.
\item
  When late-2026 hybrid and sparse mixture-of-experts language models up
  to \texttt{34.66B} parameters stream 4-bit weights from solid-state
  storage through custom fused Apple Metal shaders, router-sparse expert
  reads paired with that zero-FLOP \texttt{LUT6} drafter cut disk reads
  by up to \texttt{12.30×} and hold \texttt{Qwen/\allowbreak{}Qwen3.\allowbreak{}6-\allowbreak{}35B-\allowbreak{}A3B} in
  \texttt{970.0} megabytes of active weight memory (\texttt{1.47\%} of
  its \texttt{66.11}-gigabyte 16-bit floating-point footprint) at
  \texttt{6.\allowbreak{}773\ J/\allowbreak{}tok} on-chip \texttt{reported\_\allowbreak{}j} with zero change to
  the output tokens; gating code and multi-file git-repository commits
  behind deterministic \texttt{pytest} checks reaches
  \textbf{\texttt{87.50\%} verified pass rate} across both a
  \texttt{48}-task (\texttt{16} specs × \texttt{3} waves) frontier
  coding bakeoff and a \texttt{16}-task (\texttt{8} git repos ×
  \texttt{2} waves) repository patching benchmark with
  \textbf{\texttt{0.00\%} broken commits admitted}, accelerating
  crystallized Wave-3 solves by \textbf{\texttt{15,401×}}
  (\texttt{2.89\ ms}, \texttt{0.0424\ J} \texttt{reported\_\allowbreak{}j}).
\end{enumerate}

\subsection{1.1 Architectural background and
contributions}\label{architectural-background-and-contributions}

In \href{https://research.openie.dev/papers/gates/}{Metered Commit
Gates} \texttt{{[}same\ house{]}}, Part II defines \textbf{Mixture of
Limits}: try gears in decreasing order of pass probability per joule
\(p_i / c_i\) (Simon and Kadane, 1975), stop as soon as the task
completion predicate \(C(z) = 1\) holds, and forbid strengthening
\texttt{ModelGenerated} output into \texttt{Deterministic}. A static
Lookup tier, however, covers only the entries written into it before
deployment. Conversely, existing lookup-table neural networks ---

\subsection{2.1 Result 1: Cascade ordering with amortized downward
compilation}\label{result-1-cascade-ordering-with-amortized-downward-compilation}

Consider gears \(i \in \{0, 1, 2, 3\}\) tried sequentially on an input
\(x\). Gear \(i\) closes \(C(z) = 1\) with probability \(p_i\) at
expected analytical energy \(c_i > 0\). By Simon and Kadane (1975),
expected spend

\[\mathbb{E}[J_\sigma] = \sum_{k=1}^{n} c_{\sigma(k)} \prod_{j < k} \bigl(1 - p_{\sigma(j)}\bigr)\]

is minimized if and only if gears run in non-increasing order of
\(p_{\sigma(k)} / c_{\sigma(k)}\). Suppose a stationary regime
\(\mathcal{D}_r\) persists for \(\Delta T\) remaining queries where the
wake path closes with \(p_{\text{wake}} = 1\) at cost
\(c_{\text{wake}}\). Expending one-time compilation energy
\(E_{\text{compile}}\) after \(N_{\text{wake}}\) certified wakes
produces a Rung 0 \texttt{LUT6} page with certified hit rate
\(p_0' \in (0, 1]\) and lookup cost \(c_0 \ll c_{\text{wake}}\).

\textbf{Proposition 1 (Net energy condition for downward
crystallization).} \emph{Downward compilation reduces expected
cumulative analytical spend over horizon \(\Delta T\) if and only if}

\[\Delta T \cdot \bigl(p_0' c_{\text{wake}} - c_0\bigr) > E_{\text{compile}}, \qquad \text{and} \qquad \frac{p_0'}{c_0} > \frac{1}{c_{\text{wake}}}.\]

\emph{Proof.} Without crystallization, \(\Delta T\) queries cost
\(\Delta T \cdot c_{\text{wake}}\). With crystallization at cost
\(E_{\text{compile}}\), Rung 0 precedes the wake path whenever
\(p_0'/c_0 > 1/c_{\text{wake}} \iff c_0 < p_0' c_{\text{wake}}\), and
each query costs \(c_0 + (1 - p_0') c_{\text{wake}}\), saving
\(p_0' c_{\text{wake}} - c_0 > 0\) per step. Summing over \(\Delta T\)
steps yields net savings
\(\Delta T(p_0' c_{\text{wake}} - c_0) - E_{\text{compile}} > 0\). Under
rapid churn (\(\Delta T \le \Delta T^*\)), compilation loses energy,
motivating \texttt{SleepCrystallizer}'s minimum wake buffer
\(N_{\text{wake}}\) and holdout gate \(\tau_{\text{agree}} = 0.985\).
\(\blacksquare\)

\subsection{\texorpdfstring{2.2 Result 2: Non-blocking
\(512 \times 512\) Beneš--Copy--Beneš multicast
routing}{2.2 Result 2: Non-blocking 512 \textbackslash times 512 Beneš--Copy--Beneš multicast routing}}\label{result-2-non-blocking-512-times-512-beneux161copybeneux161-multicast-routing}

A Rung 0 bank of \(G = 80\) dynamic \texttt{LUT6} cells requires
\(M = 6G = 480\) input pins selected from an \(N = 512\)-bit bus with
arbitrary fan-out. A bijective Beneš permutation network cannot
replicate high-fan-out wires, whereas flat \(512:1\) multiplexer
crossbars overflow the KV260 (\texttt{119,478} CLB LUTs already at
\texttt{384} ports).

\textbf{Theorem 2 (Contention-free multicast via Beneš--Copy--Beneš).}
\emph{For \(N = 2^n\) (\(n=9, N=512\)) and \(M \le N\) (\(M=480\)), any
many-to-one multicast map
\(\phi: \{0, \dots, M-1\} \to \{0, \dots, N-1\}\) routes without
contention through \(\mathcal{B}_1 \to \mathcal{C} \to \mathcal{B}_2\)
in}

\[D(N) = 2(2\log_2 N - 1) + \log_2 N = 5\log_2 N - 2 = 43 \text{ stages}\]

\emph{of \(N/2 = 256\) SRAM-configured \(2 \times 2\) switches
(\(11,008\) configuration bits), computed in \(O(N \log N)\) time with
zero FPGA place-and-route.}

\emph{Proof.} Let \(U = \{s_1, \dots, s_r\}\) be the distinct active
inputs with fan-outs \(\sum_{j=1}^r m_j = M \le N\) and partial sums
\(S_0 = 0, S_j = \sum_{i=1}^j m_i\). Concentration \(\mathcal{B}_1\)
(\(17\) stages) maps \(\pi_1(s_j) = S_{j-1}\) via Waksman bipartite
2-coloring (Beneš, 1965; Waksman, 1968). Copy network \(\mathcal{C}\)
(\(9\) butterfly stages) replicates each \(S_{j-1}\) across disjoint
monotonic interval \([S_{j-1}, S_j - 1]\) without link contention by
Thompson's monotonic copy construction (Thompson, 1978; Lee, 1988).
Output Beneš network \(\mathcal{B}_2\) (\(17\) stages) permutes
\([S_{j-1}, S_j - 1]\) bijectively onto \(\phi^{-1}(s_j)\).
\(\blacksquare\)

\subsection{2.3 Result 3: Joint-mode minterm synthesis vs.~marginal
coordinate
argmax}\label{result-3-joint-mode-minterm-synthesis-vs.-marginal-coordinate-argmax}

Independent bit-plane DiffLogic layers predict multi-bit bursts
\(\mathbf{Y} = (Y_1, \dots, Y_B)\) via coordinatewise rounding
\(\hat{y}_b(c) = \mathbb{I}[\Pr(Y_b = 1 \mid c) > 1/2]\), which blends
correlated branches into invalid \textbf{chimera} tokens.

\textbf{Proposition 3 (Dominance and zero-chimera property of joint-mode
minterms).} \emph{For discrete context \(\psi(X) = c\) and
\(B \le 64\)-bit burst space \(\mathcal{Y}\), the joint-mode table
\(T^*(c) = \arg\max_{\mathbf{y} \in \mathcal{Y}} \Pr(\mathbf{Y} = \mathbf{y} \mid c)\)
satisfies
\(\Pr[\mathbf{Y} = T^*(\psi(X))] \ge \Pr[\mathbf{Y} = \hat{\mathbf{y}}^{\text{marg}}(\psi(X))]\),
stays inside \(\operatorname{supp}(\mathbf{Y} \mid c)\), and avoids
marginal chimeras (where mass \(0.40, 0.35, 0.25\) on
\((1,1,0), (1,0,1), (0,1,1)\) rounds marginally to invalid \((1,1,1)\)
with \texttt{0\%} exact match vs.~\texttt{40\%} for \(T^*\)). For
vocabulary \(|V|\) with \(b_V = \lceil \log_2 |V| \rceil\), one
\texttt{uint64} word packs \(K = \lfloor 64 / b_V \rfloor\) BPE tokens
(\texttt{16b\ ×\ 4\ =\ 64b} on \texttt{LFM2.\allowbreak{}5-\allowbreak{}350M};
\texttt{18b\ ×\ 3\ =\ 54b} on \texttt{Qwen3.\allowbreak{}5-\allowbreak{}0.\allowbreak{}8B-\allowbreak{}Base}).}
\(\blacksquare\)

\subsection{\texorpdfstring{2.4 Result 4: Oracle-free latent
\texttt{JEPA-EBRM} Split-Conformal + Online ACI
gate}{2.4 Result 4: Oracle-free latent JEPA-EBRM Split-Conformal + Online ACI gate}}\label{result-4-oracle-free-latent-jepa-ebrm-split-conformal-online-aci-gate}

To prevent hallucinated self-distillation when no deterministic
\texttt{RCE} check is available, the reference scores candidate pairs
using a radially regularized latent energy:

\[E_\phi(x, y) = \frac{1}{2}\|f_\theta(x) - \mu_y\|_2^2 + \frac{\lambda_r}{2}\|f_\theta(x)\|_2^2 + \psi_\phi(f_\theta(x), y), \qquad \lambda_r > 0, \quad |\psi_\phi| \le C_\psi.\]

Held-out Split Conformal calibration sets \(\hat{Q}_{1-\alpha}\), and
online Adaptive Conformal Inference updates
\(\alpha_{t+1} = \alpha_t + \gamma(\alpha - \text{err}_t)\) (Gibbs and
Candès, 2021), admitting \((x, \hat{y})\) into
\texttt{SleepCrystallizer} only when
\(|\mathcal{C}_t(x)| = |\{y : E_\phi(x,y) \le \hat{Q}_{1-\alpha_t}\}| = 1\)
(\texttt{Conformal-\allowbreak{}bounded}). By Vovk et al.~(2005) and Gibbs and Candès
(2021), exchangeable marginal coverage is at least \(1-\alpha\),
long-run shifted miscoverage converges to \(\alpha\), and every
off-manifold ray exceeding radius
\(R(\alpha_t) = \sqrt{2(\hat{Q}_{1-\alpha_t} + C_\psi)/\lambda_r}\)
yields \(\mathcal{C}_t(x) = \emptyset\) (\texttt{Refuse} / abstain).

\section{6. Limits, threats to validity, not claimed, and
falsifiers}\label{limits-threats-to-validity-not-claimed-and-falsifiers}

\textbf{Internal and construct validity.} Under uniform random noise or
per-step adversarial churn (\(\Delta T = 1\)), Proposition 1 gives zero
downward compilation savings and falls back to \texttt{1.\allowbreak{}00\ tok/\allowbreak{}sweep}.
Lossless parity (\texttt{100.0\%}) guarantees bit-for-bit agreement with
greedy target decoding without raising the capability ceiling of a
\texttt{350M} or \texttt{0.8B} base checkpoint.

\textbf{Measurement validity and not claimed.} Analytical joule and
switching-power numbers (\texttt{est\_j/VC}, \texttt{est\_\allowbreak{}j/\allowbreak{}tok},
\texttt{est\_\allowbreak{}mJ/\allowbreak{}Byte}, and the \texttt{Verilator} \texttt{VCD} +
\texttt{AMD\ DS925} \texttt{0.72\ V} \texttt{est\_\allowbreak{}pJ/\allowbreak{}cycle} and
\texttt{est\_mW} bounds in §4.16), operating-system / on-chip counter
readings (\texttt{reported\_\allowbreak{}j} from Apple Silicon \texttt{L2}
\texttt{libIOReport}
\texttt{\textquotesingle{}GPU\ Energy\textquotesingle{}} + \texttt{L3}
\texttt{proc\_\allowbreak{}pid\_\allowbreak{}rusage} \texttt{ri\_\allowbreak{}energy\_\allowbreak{}nj}, plus a
\texttt{\textgreater{}\ 450\ W} narrow-register rollover filter
documented in \texttt{Claim\ LA-\allowbreak{}11}), and whole-machine macOS
\texttt{PMU} cumulative deltas are kept strictly separate from physical
rail measurements (\texttt{measured\_\allowbreak{}j\ =\ None}). Yosys \texttt{0.71+}
and Verilator \texttt{5.054} establish structural \texttt{xck26} netlist
synthesis, \texttt{CPI\ =\ 1} cycle simulation, and \texttt{VCD}
