## Full continuous script (George cut)

Most computers rush to answer. Few stop to ask whether the answer is worth the energy and the work. That pause is not hesitation. It is the first design choice of efficient intelligent automation.

Energy efficient compute spends fewer joules for the same useful result. Resource efficient compute spends fewer scarce things. Memory bandwidth. Model calls. Human attention. Irreversible actions. Intelligent computer automation needs both kinds of thrift at once.

Physics sets floors under computation. Erasing information has a thermodynamic lower bound. Call that a MoL floor when a grammar or proof says the work is already covered. If the request is covered, you do not open a large model at all. Those floors are design limits. They are not board measurements.

Intelligent computer automation is not only chat. It is software that can move matter, spend money, write files, or call tools that cannot be undone. When a system can act, ranking answers is the wrong type at the boundary. Permission is the type that matters.

A proposal may not authorize itself. Before an irreversible step runs, the system checks a certificate. Allow bits and energy predicates must hold together. If either fails, the system refuses and records why. If both hold, it commits. That is notational intelligence as a runtime law, not as a slogan.

Proposals are getting cheaper almost every quarter. Irreversible effects are still scarce. Energy. Attention. Trust. The right to change the world once. When generation is satiated, stop. When the effect is scarce, refuse. That pairing is how efficiency survives abundance.

So the stack does four quiet things. It measures analytical cost without inventing board watts. It routes work to the cheapest mechanism that still fits. It refuses actions the certificate cannot support. And it leaves a receipt a person can read later. Measure. Route. Refuse. Receipt.

This film does not claim a measured joule from a board. It does not claim silicon leadership. Where energy appears on screen, treat it as illustrative or analytical. Board synthesis claimed equals false until a meter reading exists.

Energy efficient compute. Resource efficient compute. Intelligent computer automation that knows when to act, and when to stop. That is the OpenIE thesis we are building toward.
