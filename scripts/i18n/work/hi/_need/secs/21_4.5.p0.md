`rce form` एक विनिर्देशन और उसके फ़िट को लेता है और एक Form IR से पाँच लक्ष्य उत्सर्जित करता है:

```
.rce spec + fit
  lower ─► normalize ─► egg e-graph, equality saturation (+ admitted proposals)
  ─► extract (cost = est_j) ─► Form IR (typed relations, regions, rules with SHA-256 ids)
     ├─ Rust crate (pure step, typed state, SHA-256 log and fold, tests)
     │  └─ WASM (the same crate on wasm32-wasip1)
     ├─ Python (standard library only)
     ├─ XState v5 machine
     └─ SCXML document, executed by SCION
```

IR हर संख्यात्मक किनारे पर एक व्यवहार को ठीक करता है: जाँच किया गया 64-बिट पूर्णांक ओवरफ़्लो एक त्रुटि है और कभी रैप नहीं होता; पूर्णांक `/` शून्य की ओर ट्रंकेट करता है ($-7/2 = -3$); `%` भाज्य का चिह्न लेता है ($-3 \bmod 2 = -1$); शून्य से विभाजन एक त्रुटि है; फ्लोट IEEE 754 binary64 हैं और एक गैर-परिमित परिणाम एक त्रुटि है; नल और अनुपस्थित अलग हैं; समय केवल तार्किक घड़ी है। हर लक्ष्य उत्पन्न होता है। कोई भी लिखा नहीं जाता है।
