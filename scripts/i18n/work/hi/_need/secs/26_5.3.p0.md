इंजन का कर्नेल (हैश शृंखला, फोल्ड, नाम-मुक्त स्थितियाँ और हैंडलर मूल्यांकन) Rust के लिए Kani मॉडल चेकर से जाँचा जाता है [32]। हैंडलर मूल्यांकन एक गैर-पुनरावर्ती कदम का निश्चित बिंदु होता है, और Kani संरचनात्मक आगमन द्वारा सिद्ध करता है कि वह कदम प्रत्येक कंस्ट्रक्टर पर कुल (total) और नियतात्मक है। दस हार्नेस को Kani 0.67.0 के साथ सत्यापित किया गया है, जिसमें 7,425 जाँचों में से 0 विफल हैं:

| Harness | गुणधर्म |
|---|---|
| `chain_appended_verifies` | एक जोड़ा गई हैश शृंखला सत्यापित करती है |
| `chain_detects_tampering` | बदली हुई प्रविष्टि श्रृंखला को तोड़ती है |
| `fold_equals_replay` | फोल्ड रीप्ले के बराबर होता है |
| `fold_rejects_wrong_state` | एक ऐसा फोल्ड जो संग्रहीत अवस्था से असहमत हो, उसे अस्वीकार किया जाता है |
| `position_is_name_independent` | नियम स्थितियाँ नोड नामों पर निर्भर नहीं करतीं |
| `reason_tokens_are_name_independent` | कारण पूरे टोकन द्वारा नाम-मुक्त होते हैं |
| `handler_core_leaves` | पत्ती हैंडलर कुल और नियतात्मक होते हैं |
| `handler_core_validate` | सत्यापन कुल और नियतात्मक होता है |
| `handler_core_pipeline` | पाइपलाइनें कुल और नियतात्मक होती हैं |
| `handler_core_ifhas` | गार्ड्स कुल और नियतात्मक होते हैं |
