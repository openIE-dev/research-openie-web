# OpenIE Research Radio & Global Rung Radar — Autonomous 6h Engine

`scripts/radio/` implements the five-stage autonomous loop backing `/radio/`, `/radio/rss.xml`, `/data/global-rung-radar.json`, and the Global Rung Radar on `avalanche.openie.dev/forecast/`:

1. **`scraper.py` — Sanctioned Open-Access Literature Intake**
   Polls four documented public scientific APIs (`arXiv`, `OpenAlex`, `Europe PMC`, and `bioRxiv`) across seven research fronts spanning agentic tool use, formal `Lean 4` verification, `FPGA`/`LUT` lookup fabrics, memory-mapped case stores, energy-proportional computing, multi-agent protocols, and quorum signaling. Deduplicates entries via `BLAKE2b-256`, `SHA-256`, normalized `arXiv` stems, and `DOI` keys.
2. **`rung_radar.py` & `reviewer.py` — 9-Rung Avalanche Classifier & Epistemic Cross-Examiner**
   Projects every external work onto the **9-Rung Computer Intelligence Avalanche & Compilation Threshold** (`R1 Search` .. `R5 Tool Use` → *Compilation Threshold* `ΔT > ΔT* ∧ C(z) = 1` → `R6 Immersion` .. `R9 Economy`), assigning `threshold_regime` (`ephemeral_rungs_1_5`, `crossing_compilation_threshold`, `compiled_rungs_6_9`), `target_tier` (`Tier 3` .. `Tier 0`), plain-English takeaways with zero unexplained acronyms, formal mechanisms, `Shape D` falsifier tests, `[T]`/`[E]`/`[M]`/`[S]` epistemic badges, and OpenIE study links.
3. **`foundry_pilots.py` & `foundry_runner.py` — Candidate Topic Foundry & `<60s` Pilot Loop**
   Synthesizes six candidate research topics with pre-declared `Shape D` null baselines and hard kill criteria, executes deterministic Python pilots under 60 seconds with wrap-safe Linux `powercap` `intel-rapl:0` `reported_j` telemetry (`board_metered=false`), and attaches the pilot verdicts and SHA-256 manifest digest into both `radio-radar.json` and `global-rung-radar.json`.
4. **`personas.py`, `studio_synth.py` & `render_launch_pack.py` — Global Studio Ensemble (`ElevenLabs eleven_v4`)**
   Voices rotating 3-person roundtables across explicitly disclosed AI-synthesized OpenIE research personas using `ElevenLabs eleven_v4` (`mp3_44100_192`, SHA-256 cached in `state/eleven_cache/`) with multicultural Microsoft `edge-tts` neural voices as a zero-key fallback. Masters `44.1 kHz`, `128 kbps` Stereo AAC `.m4a` (`-16 LUFS`, `+faststart`) alongside turn-synced `.vtt` WebVTT captions and `.json` transcripts.
5. **`radio_daemon.py` & `systemd/` — 6-Hour Autonomous Linux Scheduler**
   Protected by non-blocking `fcntl.flock`, scheduled every 6 hours via `systemd --user` (`openie-research-radio.timer`, `Persistent=true`) and user `crontab`. Run manually anytime via `python radio_daemon.py --once`. Reads `ELEVENLABS_API_KEY`, runtime paths, and `OPENIE_RADIO_SYNC_TARGET` strictly from `~/.config/openie-radio/env` (`chmod 600`) outside version control.
